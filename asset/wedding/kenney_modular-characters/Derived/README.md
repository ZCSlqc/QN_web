这些素材由原版 Kenney modular characters 的 SVG 模板派生，许可沿用原素材目录中的 CC0 声明。

- templates：原上衣、裤腰、裤腿与衣袖的独立 SVG 裁切。
- rig：原手臂与长袖各分成上下两段，各有不同圆心、不同半径的内切圆；袖圆较大。两圆的初始切割直径共线，下段各绕自己的圆心同步转动。
- formal：白色婚纱、蕾丝婚纱、新郎礼服、燕尾礼服、修身西装、马甲套装、连衣裙、旗袍。领口和肩部使用原上衣路径，外衣下摆和装饰为新增路径；裙摆从原裤腰轮廓延伸。每种服装三种色块配色，提供正反面。外套盖住裤腰，内衬为可独立选择的原上衣。
- accessories：头纱、花圈、皇冠、帽子、礼帽、绅士帽的正反图层；头纱另有后披纱。
- formal 还包括针织开衫、休闲夹克两类日常外套，内搭、外套、裤裙独立选择。
- shoes：系带皮鞋、蝴蝶结礼鞋、细跟、粗跟、绑带高跟鞋；四种配色，固定 94×42 原鞋框和内侧脚踝锚点。当前共生成 213 个 SVG。
- catalog.json：每个文件的来源与铰接几何。

项目 frontend 目录运行 `npm run assets:wedding` 可重新生成 SVG。原 Vector 与 PNG 文件保持原样。所有新素材均为矢量，不内嵌位图。
