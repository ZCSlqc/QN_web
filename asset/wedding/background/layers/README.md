# 婚礼背景遮挡层 · 首轮提取

三张透明图各自保留原背景完整画布尺寸，按相同世界坐标 `(0,0,1600,900)` 绘制，不需要凭裁切图重新猜位置。

- `foreground.webp`：底部左右两角的花坛、石柱、灯笼和花盆，合为一个前景层。
- `table-left.webp`：左侧饮品桌，包含桌布、饮料罐、杯子及桌上小食。
- `table-right.webp`：右侧甜点桌，包含桌布、甜点架、餐碟及桌上蜡烛。

使用内置imagegen，以 `../garden-orthographic.webp` 为参考独立提取三次，保留透明度。同尺寸无损源图保存在 `sources/*.webp`，完整提示词见 `prompts.json`。这些图层目前只保存在源库，不进入前端发布目录。

`preview.html` 可离线查看透明图、与原图对照以及调整叠加透明度。imagegen提取可能有少量轮廓与位置偏差，属于首轮待核对素材，不保证逐像素匹配。

当前仅提取图层，未接入页面，也未修改现有背景。原背景仍包含这些物件；后续接入前需补绘去除对应物件的干净底图，再配置桌子的前后遮挡与碰撞范围，避免重影。

重建：`node frontend/scripts/build-wedding-layers.cjs`。只在本目录生成完整画布WebP及 `catalog.json`，记录原图尺寸、透明主体边界和世界坐标。前景保留生成布局；两张桌子的生成稿存在放大和位移，按原图参考区域等比例缩放、底部对齐后放回完整透明画布。桌面细节与遮挡处由生成工具补全，非原图逐像素抠图。
