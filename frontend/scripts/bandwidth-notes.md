# 图片传输优化

- 好朋友展示图使用480px高的WebP定稿源；重复PNG已清理。更新源图后运行 `node frontend/scripts/optimize-pet-friends.cjs`。
- 猫咪只预加载当前风格的行走帧，姿势和食物道具在使用时加载。
- 旅程缩略图进入可视区域后才请求；大图只加载当前张并最多预取下一张，开启省流量模式时不预取。当前详情关闭后释放临时图片地址。
- 相册和旅程大图使用最长边1920px、质量85的WebP预览；原图不改动。既有照片首次查看时自动生成副本，之后复用。删除上传照片时一并删除预览文件。
- 私密旅程预览仍鉴权并使用 `private, no-store`。不缓存到共享CDN。
- Vite开发/预览服务的公开图片采用ETag条件缓存；文件未变化时返回304，不重传文件体。更新文件会产生新ETag，避免长时间缓存旧素材。
- GeoJSON和SVG支持gzip。API、动态模块和音乐Range请求不经过这层静态处理。
- 将 `dist` 放到其他Web服务器时，应在该服务器配置静态缓存和gzip/Brotli；Vite插件不会随静态HTML自行运行。

## 实测（2026-10-28）

本地Chromium、相同冷缓存场景：进入主人猫咪页并滚动至好朋友图片，统计资源编码后字节数（不包含HTML、JS、音乐）。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 猫咪页图片 | 8,167,922 bytes | 537,860 bytes |
| 四张好朋友图片 | 6,926,220 bytes | 65,754 bytes |
| 城市GeoJSON | 3,869,209 bytes | 1,255,382 bytes（gzip） |

猫咪页图片减少93.4%。这不是全站总流量或Sakura Frp计费流量的保证；首次访问其他页面、切换风格、查看照片仍会产生相应传输。
详细资源清单现输出到系统临时目录 `QN_web-tests/bandwidth/`，不再创建项目内的 `artifacts/`。

## 页面及动画实测（2026-10-30）

本机 Chromium、1440×1000、正式构建和临时账号，依次登录、首页、旅程、小窝、婚礼、换装、后台和核验页。音乐未播放，没有真实相册照片；表格为各阶段新增资源传输量，不能视为所有账号的固定流量。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 登录页首次资源 | 451,089 bytes | 194,763 bytes |
| 首页新增资源 | 325,701 bytes | 262,023 bytes |
| 旅程页直接冷启动 | 1,940,469 bytes | 1,684,142 bytes |
| 小窝首进状态请求 | 2次 | 1次 |
| 婚礼静止视角，5秒内背景重画 | 361次 | 0次（首次绘制后） |
| 同段婚礼主线程用时 | 约2.8秒 | 约1.3秒 |

背景画布只在初次显示、平移或窗口尺寸变化时重画，人物画布继续播放；桌面最多60帧、手机最多30帧。静态昵称、招待点和未变化属性不重复更新。猫咪坐姿进入首屏，动作图集在首帧完成后逐张加载，不会减少最终加载完整动作的总字节数。

字体从保留的TTF生成拉丁字集，保留重音、标点和连字，其他文字走系统字体；浏览器图标改用32px PNG衍生图。地图三个GeoJSON内容未改变，总计4,613,263字节，Brotli传输1,336,833字节；浏览器自动解压。同一页面会话再次进入旅程，复用已解析地图，不重复下载几何数据。

## 婚礼自制图片优化（2026-10-31）

44 张新物件从约 1.60 MiB 降到 678,708 字节（约 663 KiB），减少约 60%。原始透明图集保留，网页 WebP 使用 quality 90 与 alphaQuality 100，不缩放素材。物件按需解码，菜单缩略图懒加载，首次进入不会下载全部 44 张。共用图标按同一 URL 复用。

庭院的收款牌使用 280px WebP 预览（15,686 字节），打开弹窗后才加载并下载 1118px 原始 JPEG（约 124 KiB）。客户端不会为小牌子提前下载大原图。

猫咪动作图集仅为可见猫咪串行下载，拖动场景后再补加载新进入的猫咪；减弱动态效果不下载动作图集。已有 ETag/304 与应用内解码缓存保留，重建未变更文件不会改变发布修改时间。

## 完整整理（2026-10-31）

本轮整理前后文件大小（十进制字节）：

| 目录 | 整理前 | 整理后 |
| --- | ---: | ---: |
| asset 源素材 | 31,827,616 | 26,454,526 |
| frontend/src/assets | 11,176,528 | 202,856 |
| frontend/public | 16,298,367 | 15,610,944 |

源素材变小主要来自旧预览和叠层清理、原图集无损转 WebP；字体原稿移到 asset/shared/fonts，仅两张 WOFF2 子集参与前端构建。这些目录大小不等于单次页面下载量。

两张小窝插画动作图保持 640×640，合计从 717,462 降到 150,868 字节，减少 79%。全部 alpha 值相同，不透明区域 RGB 平均绝对误差分别 1.73/255 和 1.71/255。仅选中该形象和动作时请求。网站图标仅发布 32px PNG，大 ICO 保留作源文件。

本次浏览器测试中，冷启动小窝并滚到好朋友区域的图片为 541,447 字节，未下载未选中的插画形象。图片复访条件请求返回 304 无响应体，地图使用压缩，音乐播放前不请求文件。

后续补充蝴蝶结与贝雷帽：仅新增 4 张正反面小 SVG，发布素材总计 816 个，保留按需加载。
